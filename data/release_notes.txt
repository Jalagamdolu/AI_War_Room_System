## Release Notes — v3.2.0 "Horizon" | 2026-03-25

### Overview
Version 3.2.0 is a major feature release focused on modernising the core user experience,
introducing real-time collaboration, and improving platform performance on mobile devices.

---

### New Features

**Real-Time Collaboration Engine**
- Users can now co-edit documents and projects simultaneously (up to 10 concurrent users).
- Live cursor presence and activity indicators.
- Conflict resolution via Operational Transformation (OT).
- Broadcasts changes via WebSocket with <100 ms target latency.

**Redesigned Dashboard (UI v3)**
- Full redesign of the home dashboard using the new Horizon Design System.
- Improved navigation hierarchy with collapsible sidebars.
- Dark mode now fully supported across all surfaces.
- Responsive layout for tablets and large-screen mobile.

**AI-Assisted Search**
- Semantic search powered by an on-device embedding model.
- Natural language queries now supported (e.g. "documents edited last week").
- Search results ranked by relevance with adaptive feedback loop.

**Improved Onboarding**
- New interactive tutorial for first-time users.
- Personalised setup wizard based on user role (individual / team / enterprise).

---

### Performance Improvements
- cold start time reduced by 18% on mid-tier Android devices (A-series chipsets).
- Image loading pipeline rewritten using lazy streaming; bandwidth reduced by 22%.
- Background sync jobs consolidated to reduce CPU wake-lock frequency.

### Breaking Changes
- The legacy REST sync API (`/api/v1/sync`) is deprecated. Clients must migrate to
  the new WebSocket endpoint (`wss://api.example.com/sync/v2`) by v3.4.0.
- Third-party plugin API `PluginContext.getData()` signature changed. See migration guide.
